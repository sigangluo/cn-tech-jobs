# 社招职位看板

[![Code: MIT](https://img.shields.io/badge/code-MIT-blue.svg)](LICENSE)

把多家科技公司官网公开的**社招岗位**汇总到一个页面里，方便横向对比：各家招多少人、要求几年经验、岗位集中在哪些城市。

**在线看板：<https://sigangluo.github.io/cn-tech-jobs/>**（打开即用，不需要安装任何东西）

## 在看板里能做什么

- **对比**：各公司的岗位数、工作年限要求的分布、城市分布；每张图都能切换成数据表。
- **筛选**：按发布时间、公司、类别、城市、工作年限和关键词筛选，所有数字和图表随筛选一起变。选中某一家公司时，还会出现这家公司官网自带的筛选项（如业务线、学历）。筛选条件会写进网址，复制链接就能分享。
- **看详情**：点开任一职位查看职位描述和任职要求，并一键跳到该公司官网的原职位页。
- **下载**：页面底部可以下载各公司的 CSV，右上角可以下载完整的 JSON。

## 数据范围

- 收录的「技术」包括软件、算法、硬件和汽车研发岗位；物流、制造、设施运维、技术服务等非研发岗位不在收录范围。
- 部分公司官网没有可靠的职位类别，这类岗位按职位名推断，可能有漏收或误收；页面上有「类别推断」标记，也可以用「类别来源」筛选排除。
- 数据是某一天的快照，页面顶部写着数据日期。已下架的职位可能还会留在看板上一阵，**是否在招、具体要求均以官网为准**。
- 「工作年限」是从任职要求文本里自动识别的，个别写法特殊的职位可能识别有误。

## 免责声明

- 职位信息来自各公司官网的公开页面，**版权归原公司所有**，本项目只做整理汇总，仅供参考。
